# WonderWeb

WonderSearch ist eine Metasuchmaschine, die eine Anfrage gleichzeitig für mehrere bekannte Suchmaschinen vorbereitet und gebündelt anzeigt.

## Nutzung

1. Öffne `/home/runner/work/WonderWeb/WonderWeb/index.html` im Browser.
2. Suche nach einem Begriff.
3. WonderSearch zeigt gebündelte Ergebnis-Links aus mehreren Suchmaschinen (Google, Bing, DuckDuckGo, Yahoo, Ecosia, Brave Search, Startpage, Yandex, Baidu).
