# WonderWeb

WonderSearch ist eine einfache Suchseite, die Suchergebnisse direkt in der Oberfläche anzeigt.

## Nutzung

1. Öffne `/home/runner/work/WonderWeb/WonderWeb/index.html` im Browser.
2. Suche nach einem Begriff.
3. WonderSearch zeigt gefundene Ergebnisse direkt als Ergebnisliste auf der Seite.
